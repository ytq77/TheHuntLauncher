# TheHuntServer v0.1.0-preview.15

The Hunt Server 聚焦 BBSC 无缝联机；本次取消普通模式，简化开服与账号管理。

- Windows 窗口直接管理无缝服务，不再显示普通／无缝模式切换。
- 命令行只提供无缝开服、地址配置和账号创建，保留 `start bbsc` 用法；普通模式请求明确拒绝。
- 干净发行包不再包含普通模式目录；保留无缝所需的 shadNet、STUN、WebAPI、BBSC 游戏服务和 Relay。
- 无缝端口、账号与数据库格式、两秒召唤间隔保持原样。升级不会自动删除或转换旧 `normal/` 数据。
- 更新教程、目录说明与验证范围。服务端精简不修改客户端游戏逻辑，也不自动部署到现有云服务器。

升级前退出旧版开服程序并备份数据，保留 `server.json`、`bbsc/` 与账号备份。具体步骤见 Windows 教程。
