# 验证范围

## 已验证的兼容基线

BBport 1.9.2 + BBSC 0.0.1_items 的既有私人测试环境：

- RTX 5070 进入游戏、FSR 4、DualSense 左右触摸板菜单。
- 另一台低配置电脑继承本机 720p / FSR3 配置。
- 双人移动、战斗与伤害显示。
- 房主或客机死亡后保持连接并在提灯复活。
- 双方提灯传送后仍在同一世界。

这些结果来自优化前的兼容基线，不能替代新构建的回归测试。

## 本次改动的验证

- 安全内存扫描：边界、命中上限、空模式、不可读页面、查询后页面权限改变。
- 启动设置：每台电脑独立配置、原存档只复制一次、后续进度不覆盖、环境变量污染隔离。
- 联机配置：地址校验、凭据不放入 URL、私人账号不写入设置快照。
- WPF：Windows PowerShell 5.1 加载与界面布局渲染。
- 包装：依赖解析、私有状态排除、压缩包 CRC 与文件 SHA256。
- 2026-10-20，RTX 5070 本机：从新启动器进入存档成功；玩家确认五件道具分类、中文和图标均正常。
- 同轮日志：启动初始化线程后 12,540 ms 准备完成，首次进入角色/补齐道具在其后约 25 秒。
- 首次测试包漏放模组目录所需署名文件，导致 BBSC 停用；已补齐，并加入打包期与启动前检查。失败轮不计入初始化效果。
- 英文 Windows CI 暴露中文控制台编码错误，已让状态输出兼容当前编码，状态 JSON 保持 UTF-8。
