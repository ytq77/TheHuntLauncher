## 2026-10-21 存档转换实验

手工原型已对一台 RTX 5070 的一个角色完成：普通版基线读取、无缝副本检查、五件道具清理和四件原版道具恢复、正常保存、无模组核心离线重载。玩家确认原版道具显示正常，保留无缝版较新的等级、装备和地点；检查进程中未加载 BBSC 或转换 DLL。两边真实存档及额外桌面备份均未改变。

新增页面流程使用独立任务目录，导出而不安装。自动检查覆盖输入复制与源变化、步骤顺序、道具数量与槽位、未领铃拒绝、辅助记录拒绝、异常退出阻断导出、锁恢复、文件变化范围与导出 CRC/SHA256。上述错误场景为模拟检查，并非已完成全部实机故障测试。

多角色、未领铃的实际恢复、仓库存放、快捷栏自动清理和客机世界恢复仍待验证。未支持的条件保持阻断，详见[转换测试说明](save-conversion.md)。

页面回归发现：无缝副本保留了已装备道具，但原版占位定义使装备页无法显示它们，背包仍有已装备标记。
独立离线诊断副本仅恢复五件道具的分类与图标，玩家确认装备页随即能看到这些道具，并已卸下后正常退出。
诊断未自动写装备槽、未启动正常 BBSC。核对正常退出和目标角色文件变化范围后，保留原检查副本，将已卸下的诊断输出接回当前页面任务。
玩家随后完成「转换副本 → 普通版重载验证 → 导出」，确认五件无缝道具消失、四件原版道具正常，较新的等级、装备及地点保留。
导出包含 16 个存档文件，CRC、逐文件 SHA256 及与重载副本的一致性均通过；两边真实存档和辅助记录始终未变，没有安装或覆盖正式版。
检查模块现加入同样的显示准备及就绪检查，仍需玩家确认卸下。Python 自动检查 67 项通过，原生编译及既有扫描／提示检查通过。

随后使用修复后的辅助模块新建任务，完成「备份 → 普通版检查 → 无缝版检查并卸下 → 转换 → 无模组普通版重载 → 导出」。
玩家确认这次装备页直接显示原先隐藏的道具，卸下后完成全部步骤，全程没有人工替换或接回副本。
五件无缝道具已移除、四件原版道具恢复，领铃标记不变；玩家确认名称、图标、快捷栏及较新等级、装备和地点正常。
最终 ZIP 的 16 个存档文件通过 CRC、逐文件 SHA256 及与重载副本的一致性检查，源存档和辅助记录未改变。
此结果仅覆盖本机一个角色、已拥有原版四件道具、无缝五件均在背包且没有客机恢复记录的场景；不代表其他电脑、多角色或未支持条件已通过。
