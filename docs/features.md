# 功能与玩法

在启动器左侧打开「功能与玩法」。每项都有用途、作用范围和推荐值；保存后在下一次启动游戏时生效。
页面覆盖本包固定版本的 31 项模组设置，另列出开放入侵和游戏内队友互伤，共 33 项。
无缝召唤与基础钩子固定启用；Relay 地址在「游戏与联机」设置。

「恢复推荐」先填入推荐值，点击「保存功能设置」才会写入本机。更改后尚未保存时，启动器会提醒先保存。
已有包升级后若没有个人功能文件，会采用相同推荐值。功能设置存放在本机 `features.json`，不进入公开安装包。

## 推荐方案

保留跨区域召唤、世界同步、提灯同行、猎人梦境、死亡后保持联机、客机拾取、完整回响、取消客机生命削减、免费摇铃和死亡掉落回响。
保留入侵及五人支持；五人支持开启不代表必须凑齐五个人。
敌人缩放保持开启，额外 NPC 猎人强化关闭，永久共享世界进度关闭，Discord 状态展示关闭。
合作时不使用纷争之铃开启队友互伤；想切磋时再在游戏中切换。

多人难度默认每增加一名客机，小怪血量 +40%、Boss 血量 +100%、敌人伤害 +15%、
小怪抗硬直 +15%、Boss 抗硬直 +20%。这是替代原版 Boss 合作强化的配置。
双方应保持敌人缩放开启；处于合作时，客机数值跟随房主。更换房主后使用新房主的数值。
单人时不按客机人数额外强化。两端配置建议保持一致，以便交换房主。

## 世界同步、永久进度与物品

世界同步让客机在联机中看到房主的门、升降梯、Boss 和地图状态。
永久共享进度是另一项功能：客机归返后，把收集到的房主 Boss、捷径、门和提灯完成状态追加到客机的无缝存档，
可能包含房主在这次会话之前完成的部分；合并只增加，不撤销已经完成的进度。
NPC 支线和角色属性不由这项功能整体复制。

本包推荐关闭永久共享进度。首次开启会要求确认；再关闭也不会撤销已经合并的记录。
这项功能适合专门的合作角色。Boss 战、客机回自己世界的最终状态及旧版本存档恢复，仍需在副本上验证。
该开关不会把无缝存档自动同步到普通版。

客机拾取是独立功能。背包里的物品、角色的地图拾取标记和 `mod/guest-items` 中的辅助记录共同参与处理，
关闭共享 Boss 进度不等于撤销客机拾取。回迁普通版的完整转换仍在只读研究阶段，当前不提供无缝回普通版按钮。

## 入侵与队友互伤

「开放入侵」控制符合条件的本机单人／房主世界是否开放给入侵者。
主动入侵仍通过渴血之铃；游戏内的状态条件、服务器匹配和双方连接仍决定能否进入。
已收到私人环境中的入侵实测反馈，不代表所有地图、人数和离开方式都已覆盖。

纷争之铃控制合作队友之间的互伤。每次新进程初始关闭，房主决定切换，客机摇铃提出请求。
启动器不把游戏进行中的互伤状态当作本地持久开关，也不在后台改变正在进行的战斗。

## 本机、房主与服务器

功能页里的多数选项控制本机模组行为；难度数值由房主同步。双方尽量使用相同客户端版本和合作配置。
「游戏与联机」中的四个地址只选择本机连接目标，不会修改服务器的监听端口、账号数据库或公告。
Discord 开关只控制个人资料上的游戏状态展示，不负责游戏账号认证。

现有 shadNet 与 BBSC 游戏服务没有可供普通联机账号修改全部服务器配置的管理接口。
服务端口、注册、数据库和启停需要服务器管理员权限，部署方法见[服务端教程](server/README.md)。
游戏账号和服务器管理员身份分开处理；公开客户端不附带管理员凭据。
「服务器管理」使用已有 SSH 管理员身份查看状态、列出账号、新建与验证账号，见[客户端管理说明](server/client-admin.md)。

## 验证边界

既有私人环境已实测双人移动、战斗、死亡后保持会话、提灯同行，并收到入侵实测反馈。
新功能页经过配置类型与范围、实际环境变量、保存／恢复推荐和 Windows PowerShell 5.1 界面的检查。
Boss 战结束后保持会话、五人合作和永久进度合并尚未完成本项目的完整实测。
