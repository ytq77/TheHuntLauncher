# 无缝版转回普通版：当前角色转换测试

在「存档」页展开「无缝版 → 普通版」。这是一套需要逐步检查的实验流程，尚不是覆盖所有角色的一键回迁。
它先备份普通版与无缝版，游戏只使用任务目录中的副本，最终导出 ZIP，不替换两边的真实存档。

## 当前支持范围

- 游戏为本包固定版本的 CUSA03173 1.09。
- 玩家确认普通版基线与无缝版对应同一个角色；工具再核对本地角色槽位。
  工具尚未验证稳定的角色唯一标识，不能仅凭相同槽位自动断言同一角色。
- 原版基线的四件联机道具各一件、均在背包，梦境领铃标记已领取。
- 无缝版中五件模组道具各一件、均在背包；四件原版道具已被移除。
- 五件无缝道具没有装备在快捷栏或随身物品，需要玩家在检查副本里确认或卸下。
- 没有客机拾取、世界恢复或待合并辅助文件。存在这些记录时停止，不会删除它们。

尚未领铃、道具在仓库、数量不同、缺少可信原版基线、待恢复客机世界、多角色批量转换和快捷栏自动清理，均不属于当前支持范围。
一个任务中切换角色会停止。ZIP 包含整份存档目录，但只有目标角色经过验证；其他槽位不因此获得兼容保证。

## 测试步骤

开始前正常退出普通版和 The Hunt。两份真实存档在本轮测试期间保持不动；若另行游玩产生新进度，需要新建任务。

1. 勾选两份存档属于同一角色，点击「新建备份」。它校验游戏版本、存档路径、辅助记录及复制结果。
2. 点击「检查原版副本」，离线载入目标角色，进入场景后停留约 20 秒，再从游戏菜单正常退出。
3. 点击「检查无缝副本」，载入同一角色。辅助模块只在内存中恢复五件道具的分类和图标，供玩家核对装备；不启动正常 BBSC，不自动改写装备槽。
   名称可能仍显示 `??`，不要使用道具。在这个副本中卸下五件道具的快捷栏／随身物品装备，等待采集后正常退出，再勾选对应确认框。
   旧检查模块未恢复道具定义时，曾出现背包有已装备标记、装备页却不可见；不能据此认定已经卸下。显示定义未就绪时不接受检查结果。
4. 点击「转换副本」。进入同一角色后等待页面提示道具处理完成，再从游戏菜单保存退出。
   仅在全部条件匹配时清理五件道具、恢复已证实拥有的四件原版道具；领铃标记保持已领取。
5. 点击「普通版重载验证」。本轮直接启动原核心，不加载正常 BBSC 或转换 DLL。
   检查五件道具消失、四件原版道具名称与图标正常，等级、装备和地点仍是无缝版较新的进度。检查完正常退出。
6. 勾选人工验证确认框，点击「导出存档包」。导出包重新检查 CRC 和每个文件 SHA256，保存在本次任务目录。

原版基线只用来核对道具，不会用旧原版角色覆盖无缝版的新进度。此流程不合并两个分支的进度。

## 保存、失败与中断

每个任务位于安装目录的 `conversion-jobs/<任务编号>/`。里面包含：

- `backup/`：复制并核对后的两份原始输入；
- `baseline/`、`inspect/`、`convert/`、`verify/`：每步独立运行的配置、存档和日志；
- `mod/`：独立辅助模块及本任务观察记录；
- `job.json`：任务状态和来源核对记录；
- `converted-save.zip`：仅在普通版重载和人工确认后生成的导出包。

异常退出、复制失败、源存档变化或状态不匹配时，不生成可用导出。保留失败副本便于排错，新建任务从完整输入重新开始。
如果辅助进程意外结束，先正常关闭残留游戏窗口，再新建任务；确认旧进程已不在且游戏关闭后才回收旧锁，旧副本不会被清理。
此设计通过不改写真实目标避免半完成替换；本版没有「直接写回普通版」按钮，也没有真实目标替换的回滚操作。

`conversion-jobs`、任务指针和锁均属本机私人数据，不进入客户端安装包或源码包。

## 已验证与待测试

手动原型已在一台 RTX 5070 电脑的一个角色上完成：副本道具处理、正常保存、不加载模组的普通版重载，玩家确认保留较新进度。
页面版已对同一角色完成转换、普通版重载和导出，玩家确认道具与较新进度正常；ZIP 的 CRC、逐文件 SHA256 及与重载副本的一致性通过，两边真实存档未变。
首次测试中途通过独立显示诊断副本卸下了原本不可见的已装备道具，再接回页面任务。
修复后又新建任务完整重跑：装备页直接显示道具，玩家卸下后完成转换、重载和导出，全程无需人工替换副本；本机一个角色通过，其他电脑／角色尚未验证。
自动检查覆盖步骤顺序、输入变化、错误数量／槽位／领铃状态、显示定义未就绪拒绝、异常退出、锁恢复、导出校验及私人文件排除；不能代替其他电脑／角色的真实游戏验证。

当前测试流程需要四次进入游戏，分别检查普通版、检查并卸下无缝道具、转换、用普通版重载。
后续考虑合并检查与转换步骤，保留备份和转换后重载；该简化尚未实现，本版不承诺自动清理装备引用。
