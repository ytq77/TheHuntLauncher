# 普通版与无缝版的奖杯记录

BBport 的角色存档与奖杯记录分开保存。成就页面读取实际用户目录中的 `trophies.log`，内容为每行一个奖杯编号和 Unix 解锁时间。角色已经击败某个 Boss，不等于这个文件一定保留了当时的解锁事件。

## 自动处理的入口

- 首次创建无缝环境：从所选普通版的实际用户目录读取奖杯记录，随独立存档一起导入。
- 存档页手动导入普通版：合并普通版与现有无缝版的奖杯记录；不会清掉无缝版独有的已解锁项目。
- 无缝转普通版的新转换任务：备份双方奖杯记录，将合并结果写入导出 ZIP；选择“转换并替换原版”时，同时备份和合并原版奖杯记录。

按奖杯编号去重，同一奖杯保留最早的有效解锁时间。编号包含本体与 DLC（0–39）；只处理实际记录，不扫描角色进度补发奖杯，不主动合成白金。普通版启动器自身仍可能根据已记录的全部本体奖杯授予白金。

普通版实际用户目录沿用启动器 `user_dir` 设置，默认是普通版安装目录下的 `user/`。无缝版是 The Hunt 的 `data/user/`。记录属于用户环境，合并后包含该环境下所有角色已记录的奖杯，不按当前转换角色删减。

## 导出与备份

新 ZIP 除 `savedata/` 外，还包含 `trophy-sync.json`；有有效奖杯记录时包含顶层 `trophies.log`。后者应放在目标实际用户目录，和 `savedata` 同级。目标已有该文件时，不要直接覆盖丢掉目标独有记录；建议使用 The Hunt 的“转换并替换原版”，自动合并并备份。

首次导入的原始记录备份在 `data/trophy-import-backup/`。手动导入的奖杯备份在本次 `save-backups/import-时间-编号/trophies/`；转换任务的输入备份在 `conversion-jobs/任务编号/backup/trophies/`。替换原版时，旧原版奖杯另存在原版 `save-conversion-backups/本次目录/trophies/`，与旧 `savedata` 同级。备份保留原始字节和摘要，合并结果通过临时文件原子替换。

来源记录缺失时，界面说明无法补齐历史奖杯，保留目标已有记录；格式无效的行被跳过并计数，原文件仍备份。操作期间记录有变化会停止，避免套用过期记录。遇到写入错误会尝试同时回滚本次存档替换及奖杯修改，错误和备份位置会保留。

该功能只随上述新建操作执行，不持续跨目录同步，也不会在程序更新时扫描或改动已有记录。旧转换任务与已导出的旧 ZIP 不会被自动改写。仅有角色存档、没有任何奖杯记录时，无法完整还原历史解锁。
