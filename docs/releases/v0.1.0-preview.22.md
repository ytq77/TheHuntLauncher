# The Hunt preview.22（审查后候选，未发布）

[使用文档 / 快速开始](https://github.com/ytq77/TheHuntLauncher/blob/v0.1.0-preview.22/README.md#快速开始) · [验收表](https://github.com/ytq77/TheHuntLauncher/blob/v0.1.0-preview.22/docs/validation-current.md)

- 修复合作客机跟随跨图后使用断鸣空弹时，可能播放成吃东西动作的问题。
- 恢复房主摇动纷争之铃开启或关闭互伤时的铃声。
- 启动器左下角新增「使用文档」，点击后在默认浏览器打开快速开始。
- Windows 客户端附带诊断收集器，默认仅导出筛选后的日志和版本、恢复状态；完整存档收集需手动开启。
- 私服客机只有在确认加载了房主所在地图后，才会被移动到房主身边，避免把其他地图的坐标套用到当前地图。
- 存档恢复改用原生成功读档确认的角色槽位与会话凭据；没有完整个人基线时阻止合作入房，修正两代存档完成核对。
- 导入、普通版转换和程序更新增加持久替换记录、中断识别与保留备份；导入前严格检查完整存档来源。
- 加固跨图状态、互伤对象与超时处理、首次猎具迁移、钩子并发取消和 Lua 事件分派。
- 客户端与服务端账号操作统一通过 stdin 传递凭据；补齐界面异常、请求超时和更新清理。
- 私服 Relay 升级为原生账号认证、签名与防重放，按真实房间和房主权限转发；四类召唤接口绑定认证账号，入房前位置定向发送并可撤销。客户端和私服需同步升级。
- 服务端保留令牌吊销、STUN 登录来源、损坏数据保护和受信网络监听；底层 NP/HTTP 仍使用受信 LAN/VPN。
- 打包改为显式源码清单和干净的服务端编译输入，补齐隐私拒绝规则、部署说明与第三方通知。

此前 preview.22 候选的双机测试中，房主通过提灯回到猎人梦境后，未重复弹出摇铃提示，已加入的客人仍在。本版不会在传送后自动重摇唤猎之铃，也不会主动取消招募；跨图后能否继续招到新客人仍未验证。

继续使用 **BBport 1.9.7**。用户已确认前一个加固测试包的登录、招募、入房、传送、离房、普通版导出和灯点正常。新 Relay 协议单独进行构建及原生服务测试，不能沿用该轮实测作为新协议的游戏验收；旧服务没有自动升级。详见[加固记录](../hardening-20261105.md)。
