## 本版更新

- 「存档」页新增无缝版转普通版的离线入口，可直接导出 ZIP，或完整备份旧原版后替换；转换期间无需启动游戏。
- 自动清理快捷道具栏、当前选中道具及随身物品栏中的无缝道具引用。恢复的四件原版联机道具只放背包，其他装备保持原样。
- 根据文件头定位有效角色数据，避免把文件尾部残留的旧数据副本当成当前背包。异常布局、数量、所有权或引用状态会停止转换。
- 保留旧的分步诊断流程；输出包增加字段改动记录，替换失败时尝试恢复旧原版。
- 包含最新游戏内中文措辞、功能与玩法说明，以及通过 SSH 查看服务状态和管理联机账号的页面。
- 补充客户端覆盖升级说明，排除私人存档、账号和转换备份进入公开包。

## 下载与升级

下载 `BBSC-Launcher-0.1.0-preview.3-windows-x64.zip`。源码包供构建和研究使用，SHA256SUMS.txt 提供文件校验值。

退出游戏和启动器，将新版 ZIP 内的程序文件与子目录覆盖到原 The Hunt 目录，再重新打开。保留本机的 `data`、`.private`、`profile.json`、`features.json` 和 `server-admin.json`；不要把另一台电脑的整份运行目录复制过来。首次安装则完整解压到新目录。

## 验证与范围

离线生成的副本已在一个 RTX 5070 本机角色上完成无模组普通版重载、正常保存及保存后的物品／装备字段复核。用户确认原版道具只在背包，其他装备、进度和画面正常，并在进一步核对后授权发布。自动检查涵盖备份、导出、替换失败恢复和私人文件排除。

当前离线转换只支持已验证的 CUSA03173 1.09 布局、一名角色持有完整五件无缝道具、原版同角色已拥有四件原版联机道具的情况。未领齐、仓库目标道具、多角色批量转换和客机世界恢复辅助记录暂不支持。替换会回写整份存档目录，不合并两条进度分支。

这是预发布版。BBport 固定为 1.9.2，本版未升级核心或私人服务器协议。
