# The Hunt 0.1.0-preview.7

本次为正式版前的预览更新，包含此前仅在本地测试的 1.9.4 适配与自动更新功能。

## 更新内容

- 固定 BBport 1.9.4，继续使用 BBSC 0.0.1_items 与 CUSA03173 1.09。
- 补齐并校验 DLSS 桥接、NVIDIA SR/FG、FSR 4.1.1 与 AMD ML-FG 组件及许可，修正能力检测工具目录，避免漏包导致 DLSS 回退至 FSR3.1。
- 同步本机普通版画质、帧率、低显存与按键设置；首次替换已有按键前保留备份，不使用其他电脑的配置。
- 修复免费摇铃取消后凭空增加 1 点灵视；用户已确认游戏内验证通过。
- 新增自动更新：查询 GitHub 发布版本，下载并核对 SHA256，备份和替换程序，自动重新打开，保留账号、存档和个人设置。
- 「检查更新」改为「启动游戏」旁的独立按钮。支持可选 HTTP 代理、GitHub 下载加速和预览版频道；仅从第三方加速站取得校验值时不会启用自动安装。
- 源码附件排除安装器测试生成的临时目录与测试状态。

## 升级说明

此前公开的 preview.5 及更早版本尚无更新模块，首次升级请手动将完整包内的程序文件覆盖到原 The Hunt 目录，并保留自己的 `data`、`.private`、`profile.json` 和功能设置。不要复制另一台电脑的整个安装目录。之后可从程序中检查并自动安装新版本。

本更新只升级 The Hunt 客户端，不替换普通版官方启动器，不更新服务器。操作前请正常退出游戏并结束存档或服务器管理任务。程序备份位于 `update-backups/`，详见[自动更新说明](../updates.md)。

## 验证与限制

当前已完成 1.9.4 的 RTX 5070 独立副本验证：在线加载、五件道具分类/中文/图标、左右触摸板与 DLSS 画面正常，正常退出返回 0。存档转换已完成此前记录的原版重载验收；灵视修复有用户实机确认。

自动更新已完成版本选择、下载校验、数据保留、占用回滚、父进程等待与重启的独立检查。preview.6 → 本公开包的真实自动升级将在本包发布后验证，此说明不提前将该项标记为通过。

Boss 战及之后保持联机仍待回归。存档转换继续限于已验证布局，遇到未知或未恢复的客机记录会阻止操作；不新增对未知布局的支持。无缝环境的人偶洗点暂时关闭。显卡设备丢失问题未在本次更新中修复，不能将本包视为相关崩溃的修复版本。
