# The Hunt 0.1.0-preview.9

本次继续使用 BBport 1.9.4，重点修复联机状态恢复与存档操作防护。

- 修复客机跟随房主进出猎人梦境后，NPC 剧情状态可能被房主状态覆盖的问题。现在在入房前保留原值；双人往返、指定遣返、正常保存和单人重载测试通过。
- 加强普通版存档导入：验证复制源稳定及结果完整，隔离旧分支已完成的辅助记录，遇到待恢复或未知记录时停止；失败时回滚并保留必要的恢复信息。
- 存档转换始终校验事件区结构，并核对输出事件区与源副本一致。
- 确认停止召唤后，清理没有同伴的旧房间；不把普通菜单浏览或取消确认当作结束房间。
- 补充原生回归测试与状态恢复说明。

此更新不会自动修复已经受影响的历史 NPC 进度，也不会合并两套存档。已有账号、存档和本机画质继续保留。详见 `docs/npc-state-recovery.md` 和 `docs/save-conversion.md`。

本轮没有把入房等待时间的改善作为修复结果；匹配成功、信令成功与实际进入同一世界仍分别核对。死亡、强退、入侵和交换房主的组合尚未完成本轮实机回归。
