# The Hunt Windows 预览版 0.1.0-preview.26

两台电脑使用同一个 Windows x64 客户端。在游戏内摇唤猎铃开房，摇应猎铃加入。两端连接同一台配套 Windows 私服。已有 preview.25 客户端沿用启动器的「检查更新」入口。

## 联机与存档

- 房主撤销空房并换位置重新开房后，新的邀请会绑定新房间、客机报名和房主当时的位置。客机按本次有效邀请处理跨图入场。
- 客机团灭后跟随房主回灯时，客户端会在已确认的回灯任务上检查角色是否恢复行动。
- 存档页会显示所选备份中角色的姓名、等级和血之回响。主备为同一角色且三项相同时合并显示。只有备档的角色也会列出，空槽隐藏，无法识别的非空数据保留提示。处理页可分别查看恢复来源与当前进度。

## 双机实测

2026 年 11 月 21 日，两名玩家使用同一份 Windows 客户端，各启动一次，在游戏中轮流开房。两个方向都成功会合，双方均能走动。每一轮的客机断开后都回到了自己的世界。

双机实测快照的 SHA-256 以 `561533744614` 开头。发布客户端为存档页的旧分步诊断补入了原版离线核心，并更新了诊断代码和发行资料。联机核心、联机模组、正常游戏启动入口和配套服务端均与实测版本逐字节一致。发布包的完整 SHA-256 见下载区的 `SHA256SUMS.txt`。

## Windows 下载

- `TheHuntLauncher-0.1.0-preview.26-windows-x64.zip` 供两台游戏电脑使用，内含配套服务端。解压后运行 `TheHuntLauncher.exe`。
- `TheHuntServer-Windows-v0.1.0-preview.26.zip` 供单独部署 Windows 私服使用。

从 preview.25 更新前，请先退出游戏。使用内置服务端的电脑也请先关闭服务端窗口。

**已知问题**　客机在房内直接退标题，重读角色后可能出现在房主地图。请先断开联机，等回到自己的世界并能走动，再从系统菜单保存退出。
