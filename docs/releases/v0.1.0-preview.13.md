# The Hunt 0.1.0-preview.13

本次预览加入普通版与无缝版之间的奖杯记录合并，补充洗点支持范围，并记录“退出到桌面”的双人实测结果。核心仍固定 BBport 1.9.4，账号、配置和现有存档保留。

## 奖杯随存档操作合并

- 首次创建无缝环境、手动导入普通版，以及新建的无缝转普通版任务，自动处理真实的 `trophies.log`。
- 按奖杯编号去重，保留最早解锁时间；保留目标原有奖杯，不根据角色进度推断补发。
- 导出 ZIP 携带合并记录、摘要与使用说明；“转换并替换原版”同时备份并合并原版奖杯文件。
- 来源缺少奖杯记录时明确提示；无效行跳过并计数，原文件保留备份。复制期间记录变化会停止，写入失败时尝试回滚存档与奖杯。
- 奖杯合并不等于合并两份角色剧情进度。旧转换任务、旧 ZIP 和现有奖杯文件不会因升级被自动改写。详见[奖杯说明](../trophies.md)。

## 洗点说明

**无缝版暂不支持人偶洗点。需要洗点可使用普通版启动器，在普通版完成全部免费等级的重新分配、正常保存退出，再把普通版存档导入无缝版。**

不要导入洗点到一半的角色：未分配额度另存在 `rebirth.txt`，当前不迁移。若较新进度在无缝版，先转换到普通版再操作；导入会整体替换无缝版全部角色，请核对来源。客户端“功能与玩法”页也增加相同提示，详见[洗点说明](../rebirth.md)。

## 退出到桌面实测

上一版退出文本修正已完成本机独立副本和双人验证：单机、房主和客机取消均保持正常；确认后游戏自动关闭，另一端正常返回或留在自己的世界；客机重载、主存档与游戏自带备份确认完成。标题菜单的文字已检查，直接点击标题退出入口未单独验证。不能据此认定上游原版 BBSC #41 的崩溃根因已解决。

## 验证与更新

199 项 Python 检查完成，新增 17 项覆盖奖杯合并、重复导入、来源缺失、格式异常、来源变化、导出及失败回滚；WPF 控件检查通过。使用两边实际奖杯日志的副本合并后，BBport 1.9.4 的奖杯解析器和跟踪器能正确读取，原日志未改动。奖杯功能无需再次联机测试。

退出游戏与启动器后，通过“检查更新”升级，或将完整包覆盖原 The Hunt 目录。保留这台电脑自己的账号、配置和存档，不要复制另一台电脑的私人目录。
