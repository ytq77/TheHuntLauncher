# The Hunt 0.1.0-preview.15

客户端与无缝服务端合入现有 TheHuntLauncher 仓库，原 TheHuntServer 仓库保留历史并设为只读。

- 启动器增加本地开服入口，完整包内置无缝服务端管理窗口；点击后由玩家选择地址、开服和创建账号。
- 可显式填入同机连接地址；账号、密码和配置不会随按钮自动改写或保存。
- 服务端取消普通模式，仅保留无缝所需的 shadNet、STUN、WebAPI、游戏服务和 Relay。无缝端口、数据库格式及两秒轮询不变。
- 游戏、启动器和服务端独立运行，关闭游戏或启动器不会自动停服；更新完整包前需关闭本地服务端。
- 客户端与服务端统一版本、源码、构建及发布，仍提供独立 Windows 服务端包和 Linux 配方。新服务端改从本仓库查询更新。
- 更新保留内置服务端的监听配置、账号、在线数据和自改的世界／记分板配置。旧普通模式目录不自动删除。

BBport 仍固定 1.9.5，BBSC 游戏逻辑与 preview.14 一致，洗点继续关闭；此前的奖励、存档恢复和退出实机结果按未改动范围复用。本版不把管理窗口、协议检查或构建通过扩大为新增游戏内验收，也不宣称修复历史灯点缺失。

完整客户端包为 `TheHuntLauncher-0.1.0-preview.15-windows-x64.zip`，保留同内容的旧名包供旧客户端更新。旧独立服务端首次迁移需手动下载新服务端包。步骤见 [本地开服](../local-server.md)。
