# The Hunt preview.25

[使用文档](https://thehunt.iytq.top/) · [验收表](https://github.com/ytq77/TheHuntLauncher/blob/v0.1.0-preview.25/docs/validation-current.md)

继续使用 **BBport 1.9.7**。本版更新启动器的存档异常处理和普通版存档来源选择；**不包含双机测试用的 P2P 逐包诊断补丁**，不修改联机协议或原生 hook。发布包由 CI 构建。

## 相对 preview.24 的更新

### 启动前处理存档异常
- 需要处理存档状态时，启动器会在存档页说明原因，给出本机可操作的选择，不再只有无法继续的“请复核”。
- 按实际可用情况，可以使用当前进度、恢复自动备份或某个角色的备档、从普通版重新导入，或确认封存后重新开始；不能确认可用性时不会假称存档已经损坏，也不会自动替玩家回退。
- 处理前先完整保全原件。仍有可读角色的处理前版本可以在备份列表里换回；换回有问题的版本后，可能再次出现处理页。整套无法读取的原件仍保留，但不承诺以后一定能找回进度。
- 中断的选择可以继续；现场变化而不能续办时，可以先完整另存当前现场，再明确放弃上次选择，重新检查。
- 从普通版重新导入会回到普通版存档的进度，不会合并无缝版的新进度；重新开始需再次确认。请阅读界面列出的影响再选择。

### 找到正确的普通版存档
- 存档页显示实际查找的完整路径和来源；自动查找按 bbport 设置的存档位置，其次是所选 Bloodborne.exe 旁边的默认 user。
- 新增“手动选择存档文件夹”。可以选 user、savedata 或正确的 SPRJ0005 这一级，启动器会换算并先只读显示角色，再由玩家确认导入。手动来源保存在本启动器中，可以清除后回到自动查找。
- 尚未初始化时也能只读预览来源角色；首次启动会确认来源。找不到普通版存档时，会明确提示进入游戏将使用空存档，以后仍可在存档页导入，不再悄悄跳过。
- 修正角色姓名显示的大端编码。普通版原存档只读，不会写回原版安装。

## 已知问题与未复测范围

- 存档异常处理页文字较长，后续页面重构时改善可读性、按钮及布局。
- **客机请先等房主结束联机，或主动断开，回到自己的世界后再退出游戏。** 联机中直接退到标题或桌面，下次可能仍在房主地图；若自己尚未到过该地图，过场和机关可能不正常。此项暂缓修复。
- 首次摇铃偶尔约 5 秒后进不去的问题仍未查明；近期定向测试均正常不等于已经修复，目前保留观察。
- 加入黑屏可能较长；入房或传送时血条早于人物、名字/出场显示时序及延迟，本版没有修复。
- 深色主题下备份下拉框选中字不清晰，点开列表可见；备份名称、位置/角色说明和大小显示留待页面重构。
- 额外状态图标含义尚未查明；团灭绕梦境和重复提示、完整断线重连、长时间连续游玩未在本版重新验收。

这是 **预发布版**。请保留重要存档的独立副本；不要自行删除状态不明的原档、保全件或处理中记录。
