# The Hunt 0.1.0-preview.12

本次预览修复游戏汉化MOD覆盖BBport新增“退出到桌面”文本的问题。BBport仍固定为1.9.4，BBSC及上一版的世界恢复修正保留。

## 更新内容

- 在最终MOD菜单文本之后生成兼容层，补齐标题菜单、系统菜单、两处操作说明和退出确认框，避免显示“意见箱”、缺失名称或缺失说明。
- 只补入退出功能需要的五条文字，保留汉化包其余译文、字体和资源；不改原游戏或原汉化MOD。
- 识别英文语言目录中的中文重译，避免新增按钮变回英文。
- 按当前有效文本生成并缓存兼容层。汉化更新后使用新输入；相同输入不重复改写缓存。
- 完整安装包已集成修正，不需要再安装单独的小补丁。

## 使用与更新

退出游戏和启动器后，通过“检查更新”升级，或使用完整包覆盖原The Hunt目录。账号、配置与存档继续保留，旧程序由更新器备份。

这项修正沿用普通版`bbport.ini`中的“退出到桌面”开关。若该功能原先关闭，更新不会自动开启。请在普通版启动器按自己的需要开启，再启动The Hunt。

## 验证范围

13项新增检查覆盖实际MOD叠加流程、五条文字的边界、其余译文保留、中文承载于英文目录、重复启动缓存及未知上游结构拒绝。另对本机实际汉化包的三个语言目录逐项核对，其他FMG内容与原汉化文件保持不变。

本版修复的是文本兼容。新增直接退出入口的取消/确认、双人合作收尾及重新读档仍需单独实机确认，不能用此前“退出到标题”的验收替代。人偶洗点仍保持原来的无缝版限制；更新代理行为也没有在本版更改。
