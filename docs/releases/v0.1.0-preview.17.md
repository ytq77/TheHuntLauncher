# The Hunt 0.1.0-preview.17

整合 C# WPF 启动器、统一的本地开服窗口和 BBport 1.9.6。

- 启动器由 C# 直接创建界面；首页固定文楷，其余页面、表单、奖杯和开服窗口固定黑体。保留所选页面图片，移除字体选择框及重复署名。
- 奖杯页读取实际解锁记录，在启动／退出游戏时刷新；新记录可在游戏右上角提示。提示随窗口同比缩放，小窗口不再固定显示大型卡片。测试提示不改变奖杯记录。
- 补齐 PC 设置中文和 FSR 4.1.2 标签，按当前汉化字库的覆盖情况使用 zhen。历史奖杯依实际记录合并，不从角色进度补发；转换并替换原版会合并双方已有记录。
- BBport 1.9.6 修复部分 Windows 电脑的 HTTPS 证书信任及证书链问题；我方菜单、运行器和保存路径适配沿用。
- 完整包附已核验微软签名与固定 SHA256 的 VC++ x64 离线安装程序。源码包包含完整字体／图片资源及许可。

本版只发布 `TheHuntLauncher-0.1.0-preview.17-windows-x64.zip` 完整客户端，不再制作 `BBSC-Launcher-*` 旧名重复附件或增量兼容包。专用 Windows 服务端、Linux 配方与匹配源码仍单独提供，正常自动更新保留。

新安装请将完整包解压到新目录并配置本机路径与账号。旧测试包请先保留原目录和进度；本版不保证早期测试结构的自动迁移。

用户已确认 1.9.5 WPF 候选的内置开服可经 Tailscale 成功入房。既有 Boss、个人商店、历史 NPC 徽章、单份掉落、退出与返家恢复结果按未改范围复用；1.9.6 核心构建及公开 HTTPS 的正确链接受／错误主机名拒绝检查通过，不扩大为新增游戏内验收。人偶洗点仍关闭，历史灯点分支问题仍按调查记录保留判断边界。
