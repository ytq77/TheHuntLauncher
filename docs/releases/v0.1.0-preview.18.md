# The Hunt preview.18

新增 SuperMedo 公共账号的 Online ID / 密码登录，分别加密保存公共账号与私服账号，启动时自动认证。笔记、血迹、游魂等内容接公共服务，无缝召唤、匹配和 Relay 继续使用原私服；公共服务失败不会静默假装连通。可主动关闭公共内容，使用私服独立池。详见[公共在线说明](../public-online.md)。

客户端入口统一更名为 **TheHuntLauncher.exe**，可选启动脚本为 **START-TheHunt.cmd**，完整包为 **TheHuntLauncher-0.1.0-preview.18-windows-x64.zip**。BBSC 模组名称和上游署名保留。

**从 preview.17 或更早版本切换，请将完整包解压到新目录，保留原测试目录和进度。** 旧更新助手固定要求旧 exe 名称，不能自动跨越此次更名；本版不附加旧名兼容入口。新名称版本之间继续支持自动更新，存档按既有已验证流程导入或转换。[升级说明](../launcher-entry-rename.md)

真实协议核对已通过公共账号认证、公共游戏登录及只读笔记查询；查询返回空列表，不作为游戏内可见性证明。离线回归覆盖协议和路由、凭据隔离、错误及清理路径，发行构建继续执行 Windows/Linux、WPF 和打包检查。

**公共内容在真实游戏内的显示与双人混合联机仍待定向验收。** 旧双机结果未走公共游戏登录，不扩大为新路径通过。既有 BBport 1.9.6 运行、小窗口奖杯提示、Boss、个人奖励等未改范围的验收继续复用；历史灯点问题仍在调查，洗点继续关闭。
