# The Hunt preview.19

更新至 **BBport 1.9.7**，固定上游源码构建。纳入游戏内重启的句柄/在线会话修正与重启后 FPS
配置重读，保留 The Hunt 的独立存档、公共内容/私服分流、用户画质设置和现有 WPF 界面。
[适配范围](../upstream-1.9.7-review.md)

合入这次定向修复：

- 清理主客切换时遗留的错误房主类型，避免客机已加入却持续出现等待提示。
- 空枪菜单只修正合作客机缺失的原生分类，保留确认/取消；修正客机主动返回时房主的缺失提示。
- 保护 NPC 的个人赠礼事件，避免在别人世界提前完成尚未领取的赠礼请求。不会自动修复历史
  受损存档，也不会按房主进度补发徽章或消耗品。

客机入场后仍可继续招募其他猎人，因此铃声与状态图标可以保留；不想继续招募时用空枪停止。
没有增加“第一名客机入场即自动停铃”。

入口为 **TheHuntLauncher.exe**，完整包为 **TheHuntLauncher-0.1.0-preview.19-windows-x64.zip**，
内置本地服务端；独立 Windows/Linux 开服包同步版本标记，服务端功能未改。
从 preview.18 可按现有更新流程升级；从 preview.17 或更早版本首次跨入口更名，请用新目录完整包。

已通过的空枪、返回和 NPC 赠礼位保护实机结果按范围复用；合作客机返回后，主/备两代存档的
全部 30 个赠礼位均与各自基线一致。发行流水线执行构建、原生/Python/WPF 与打包校验。
**1.9.7 实际游戏运行、游戏内重启后的在线重连仍待定向确认。** 旧版实机结果不扩大为新路径通过。
历史灯点、公共内容游戏内可见性和标题/读档停顿仍保留原调查结论；洗点继续关闭。
