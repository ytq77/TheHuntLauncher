## 本版更新

本版完善无缝版转换回普通版时的道具归属与客机记录检查：

- **按原版持有记录逐件恢复。** 不再要求四件原版联机道具齐全；支持一至四件的任意组合，原先没有的道具不补发。恢复的道具只放背包，两栏中的无缝道具引用自动清理。
- **区分待恢复与历史记录。** 已恢复的 `.restored` 文件只备份、不重放；客机拾取标记需在角色主存档及游戏备份中同时存在，符合条件后可转换。
- **提示具体阻断原因。** 待恢复世界、备份落后一代、缺失拾取标记、异常道具数量等情况明确说明处理方法，不通过删除记录或补写世界标记绕过。
- 每个任务原样备份辅助记录，保存检查摘要与实际恢复道具编号；这些记录不进入普通版存档包。

98 项 Python 自动检查和 WPF 检查通过，四种原版道具的全部 15 种非空持有组合均有覆盖。客机样本的 13 个拾取标记及世界标记保持不变；玩家已反馈成功导出，普通版重试读档后进入正常。首次“无法加载笔记或类似内容”的提示缺少完整文字，仍待观察。

BBport 保持 1.9.2。本版没有修改复活、碰撞、渲染或服务器协议；死亡后悬空及客机贴图异常不在本次修正范围内。

## 下载与升级

下载 `BBSC-Launcher-0.1.0-preview.5-windows-x64.zip`。本包已整合此前两份转换修正，不需要再安装测试覆盖包。

正常退出游戏及启动器，将包内程序文件与子目录覆盖到原 The Hunt 目录，再重新打开。保留本机的 `data`、`.private`、个人配置与存档备份。首次安装可直接解压到新目录。参见[升级说明](../upgrading.md)。

没有可确认的原版道具、目标道具在仓库、多角色拾取辅助记录、待恢复世界或共享进度记录等条件仍会停止；完整范围见[存档转换说明](../save-conversion.md)。
