# The Hunt 0.1.0-preview.11

本次预览主要改善无缝联机退出后的世界恢复，以及重新读档时猎具准备的体验。BBport 核心仍固定为已适配的1.9.4。

preview.10 的云端构建在补丁换行处理阶段失败，未生成公开安装包；本版修正该构建问题，包含以下已验证的更新。

## 更新内容

- 从游戏系统菜单确认退出时，恢复原生离房流程；回到标题后，同伴不必等你关闭整个程序才收到断开。取消退出确认仍保留合作。
- 提前准备当前生效的猎具定义，减少重新启动后五件道具暂时落在其他分类、显示错误图标的情况。完整特效扫描仍在后台进行，准备完成前不会提前启用纷争之铃。
- 改善客机退出后的世界恢复：保留入房前的固定存档映射，退出后先备份，再处理当前主存档；游戏自带的旧一代备份只由游戏自身推进。
- 恢复确认不再只依赖通知显示或文件修改时间：核对正确的恢复结果已经加载，并将后续原生保存凭据与两代实际角色存档匹配。地图加载产生的事件变化可以保留；缺少依据时仍停止并保留记录。
- 世界恢复尚未确认时，暂缓再次鸣铃、共享进度合并和存档转换，避免旧状态混入新会话。已归档的历史记录不会再次回放。
- 修正启动期间导入槽保护线程直接访问临时失效内存的问题。该修正针对已定位的同地址访问异常，不代表所有闪退原因都已解决。

## 更新方式

退出游戏和启动器后，使用自动更新或将完整包覆盖到原The Hunt目录。保留原有账号、配置和`data`等个人数据，不要把另一台电脑的已配置目录整体复制过来。

更新不会主动将普通版和无缝版进度互相覆盖。若提示世界记录仍待确认，请用对应角色独自加载并正常保存退出，保留相关记录，不要手动删除`own-world`或`world-recovery`目录。

## 验证范围

已完成独立副本的离线读档、道具/灯点检查，以及双人联机、客机菜单退出、关闭程序后自动恢复、重载并确认两代存档的完整流程。相关世界状态确认和内存保护也有自动测试。

这仍是预览版，建议保留自己的额外存档备份。未覆盖的长时间游玩、异常断电及其他特殊流程仍欢迎反馈；本次未更改服务器端轮询参数。
