# The Hunt preview.21

本次更新修复房主退出或断线后，客机可能留在对方地图或回到错误位置的问题。继续使用 **BBport 1.9.7**。

- 客机单独记住进入合作前的地图和坐标，跟随传送不会覆盖这个位置。两台电脑互换主客，均验证了回到原位置；双方日志也确认了房主正常退出后的返程。
- 纷争之铃只允许房主切换队友互伤。客机使用时只在自己屏幕上提示，不会打断房主招募。
- 退出桌面时清理符合条件的残留传送目标，避免误回提灯；正在进行的传送继续由游戏处理。
- 客机的拾取补偿不会提前打开箱内物品的拾取权限。已通过自动检查，该隐赫斯特箱子的实际交互留待复测。
- 修正 1.9.7 的辅助 P2P 绑定参数。两端已观测到绑定成功，怪物同步延迟是否改善仍待确认。

已知问题：进猎人梦境后，招募铃效和图标可能消失，现有合作不受影响，跨图后能否继续招人尚未确认。客机跨图后使用断鸣空弹可能播放类似吃东西的动作，正常返程和保存已验证。另有一次退出确认缺失的世界恢复场景仍在跟踪，本版保留原有保护。详见[验收表](../validation-current.md)。

已使用 **TheHuntLauncher.exe** 的玩家可从「检查更新」升级。旧入口版本首次跨更名请使用完整包。独立 Windows / Linux 开服包同步版本号，服务端功能未改，现有部署无需为本次客户端修复更新。洗点仍关闭。
