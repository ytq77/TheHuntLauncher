# The Hunt Windows 预览版 0.1.0-preview.27

## 本版变化

- 客机在房内从系统菜单退到标题，在同一进程第一次继续同一角色，会回到入房前鸣铃的位置和朝向，并保留房内收益。回到自己的世界后正常保存并退出，启动器会核对这次读入和随后的主备档。
- 两名玩家验证了这条路径。客机退标题前有 2919 血之回响，首次读回和最终两代存档都是 2919，正常退出后自动完成世界核验。再次选角、重新入房或凭据写入不完整时，启动器会保留现场供复核。
- 新首页显示角色、最近备份与个人世界核验状态，游戏运行时会跳过恢复查询。存档页可按角色查看主档和游戏备档的姓名、等级、血之回响。选择恢复来源时可查看时间、各角色进度的变化和可撤销范围。退出提示会先报告实际退出结果与可读的主档进度，再说明还有哪些世界记录待核。
- Windows 启动器和本地开服窗口更新了界面与图标。

## 安装与更新

两台游戏电脑使用同一个 `TheHuntLauncher-0.1.0-preview.27-windows-x64.zip`。完整解压后运行 `TheHuntLauncher.exe`，在游戏内摇唤猎铃开房或摇应猎铃加入。客户端内含服务端，专用开服机可使用 `TheHuntServer-Windows-v0.1.0-preview.27.zip`。

使用 preview.26 的玩家可在游戏退出后点击「检查更新」。更新内置服务端前请关闭开服窗口。各附件的 SHA-256 见同一发布页的 `SHA256SUMS.txt`。
