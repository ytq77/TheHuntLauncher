# 联机地址

四个地址对应不同服务，请向管理员索取完整值：

如果你是服务器管理员，先阅读[服务端教程](server/README.md)，其中包含普通联机与 BBSC 的区别、完整端口表、部署、备份和排错步骤。

| 字段 | 用途 | 示例（不可直接使用） |
|---|---|---|
| shadNet 合作服务器 | 账号会话与匹配 | `server.example:31413` |
| shadNet WebAPI | 账号认证接口 | `http://server.example:31415` |
| BBSC 游戏服务 | 游戏在线 API | `http://server.example:20443` |
| BBSC Relay | 无缝状态、传送等消息 | `server.example:20444` |

端口由管理员决定，表中只作格式示例。客户端依然可能需要服务端对应的 UDP / STUN 路径和玩家之间可达的网络；能打开 WebAPI 不代表全部联机路径已验证。

本包使用 shadNet 模式。无需在本启动器登录 Discord；账号属于所填写的 shadNet 服务器。也不要把公共服务器的账号误填进另一个私服。

已有私人 BBSC 环境时，填写该环境提供的地址即可。公共发布包没有默认私人地址。

密码在 `.private/account.clixml` 中由当前 Windows 用户加密保存。移到另一台电脑需要重新输入账号密码。不要上传整个已使用的启动器目录来报告问题；先检查日志是否包含个人信息。
