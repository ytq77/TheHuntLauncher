# 桌面候选 2

以下为基于 preview.16 的候选实现记录，最终整合至 preview.17；各阶段验收按当时证据保留。

## 界面

按用户最新选择，首页内容固定采用霞鹜文楷屏幕阅读版；公共导航、其他页面、表单、奖杯提示及本地开服窗口固定使用 Noto Sans CJK 黑体。移除字体选择框，不再读写旧 `desktop-settings.json`，原有偏好文件保留。内置字体按 SIL OFL 分发，来源、固定版本及摘要见 `assets/fonts/manifest.json`，许可随字体一起保留。

- Noto 字体：[官方仓库](https://github.com/notofonts/noto-cjk)，固定提交 `f8d157532fbfaeda587e826d4cd5b21a49186f7c`。
- 文楷：[官方仓库](https://github.com/lxgw/LxgwWenKai-Screen)，固定 `v1.530`。
- 首页使用用户指定的猎人与马车构图，游戏与联机、开服页使用三位信使构图。原始提供文件按字节保留，界面只做裁切和遮罩；来源摘要见 `assets/artwork/provenance.json`。
- 界面仅在左下角保留 `iytq`，移除窗口标题及横幅中的重复署名。项目及上游许可声明仍保留。

## 获得奖杯时提示

运行后端在首次存档／奖杯导入完成后建立记录基线，再观察当前无缝环境的 `trophies.log`。新编号写入本轮会话的通知状态，C# 前台在游戏窗口右上角显示图标、名称和等级。历史导入、重复编号及上一轮会话不会重弹，读取或通知写入失败不会中断游戏与世界恢复。没有新增服务器轮询或网络请求。

浮层不激活窗口、不接收鼠标输入；游戏不在前台时隐藏。当前实现是 Windows 桌面浮层，窗口／无边框为预期使用场景，独占全屏覆盖仍未实机确认。奖杯页的「测试提示」只预览通知，不写奖杯、不改变计数；游戏运行时点击后切回游戏查看。

## PC 菜单中文

补全固定 1.9.5 新增的「PC 画面」「PC 特效」「PC 设置」三页标题、25 项设置名、选项文字、说明及重启确认。只替换指定 119xxx 编号内的英文默认值或缺失值，保留已有第三方中文和其他原始文本；DLSS、FSR、平台名、分辨率及数值保留标准写法。英文等其他语言不改变。

## 桌面目录就地修正

用户在 candidate2 验证发现测试提示没有弹出、菜单中的“帧”字变为方块。窗口匹配曾错误指向 `engine/bb-probe.exe`，实际启动路径是 `bin/bb-probe.exe`；现已修正，并用真实目录布局的离屏原生窗口复现旧版失败、验证修正版取得正确 HWND。回归已加入前台构建步骤。

当前使用的汉化字体 DFPKaiW5-GB 有 4588 个字形，缺少“帧”和“渲”。按用户选择将相关标签和说明统一使用 `zhen`，标准参数值如 `60 FPS` 保留；其余缺字改用已覆盖的中文。77 项新增文本已逐字核对活动字库。游戏字体、图形参数、存档和奖励逻辑未改。实际游戏浮层覆盖与新字形排版仍待这次定向验收。

## 字体与通知可读性就地调整

用户已确认游戏内右上角奖杯提示出现；本轮只调整其可读性。提示由 360×106 放大至 540×180，图标由 58 放大至 88，名称由 16 增至 26，辅助文字增至 17／18，并提高文字与背景对比度。显示时机、五秒时长、前台窗口条件和奖杯记录处理不变。

固定引擎的 `UpscalerFsr412=6` 对应菜单编号 `119106`，但上游文字生成表仅列到 DLSS／5。已补入独立的 `FSR 4.1.2`，保留 `119103` 的 FSR 4.1.1；未改图形参数或引擎。修改同时纳入打包脚本和桌面已解压目录，下一次正常启动重建菜单文本层即可使用。

字体分区、无字体选择框、放大通知的原生布局与菜单编号检查通过。用户已通过的奖杯可见性及既有联机、奖励、退出结果继续按未改范围复用；新增观察限于提示阅读舒适度、固定字体效果和 FSR 4.1.2 标签。

## comp 小窗口通知比例

comp 的 1280×720 截图确认固定 540×180 通知占画面过大。现以先前 2560×1440 画面的 540×180 为参照，按游戏客户区宽高的较小比例缩放整张卡片；1280×720 对应 270×90，1920×1080 对应 405×135。字体、图标和内边距一起缩放，运行中改变窗口尺寸时重新计算，DPI 坐标转换沿用原生窗口变换。右上角定位、五秒时长、前台条件和奖杯记录处理不变。

普通版的 SuperMedo 登录和匹配池选项不决定 The Hunt 连接：The Hunt 明确设置自己的 shadNet 后端、服务器、WebAPI、游戏服务和账号。comp 实际运行目标若仍需确认，应读取该轮配置及运行日志，不能从普通版页面选择推断。已通关但没有 `trophies.log` 记录的项目不会按进度补发；“转换并替换原版”合并记录后，普通版奖杯页重新读取即可显示这些已记录解锁。
