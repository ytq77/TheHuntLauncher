# 公共在线内容与无缝合作

preview.18 将两类连接分开：SuperMedo 公共服负责笔记、评分、血迹、游魂及其游戏登录；你填写的私服仍负责 shadNet 匹配、无缝四类召唤 API、P2P 和 BBSC Relay。无需恢复普通合作玩法入口或一直打开普通版启动器。

在「游戏与联机」保留原有四项私服地址和私服账号，在下方填写独立的 SuperMedo Online ID、密码。可用「验证并保存账号」先检查，启动游戏时也会自动认证。没有账号可先在普通版启动器创建；Discord 不是必需条件。

每位玩家分别使用自己的公共账号及私服账号，不能让两台电脑同时占用同一个公共账号。

两套凭据使用当前 Windows 用户分别加密保存。公共账号没有固定的本地到期天数，关闭游戏或启动器不会清除；启动时自动用保存的凭据重新认证。主动忘记账号、密码失效或本机凭据不可用时才需要重新填写。公共账号已在另一游戏进程使用时，会提示先正常退出那个进程，不强制接管会话。

公共连接启用后，账号或公共服务失败会明确报错，不静默回退到私服独立内容。可主动关闭「使用 SuperMedo 公共在线内容」使用私服独立池；该状态不代表已接入 SuperMedo。两种模式都保留私服无缝合作。

实现使用仅监听本机回环地址的临时适配器。公共账号保持独立认证；游戏公共登录中的 PlatformAccountId 使用公共服实际返回的账号 ID，公共游戏会话由公共服务生成。私服 NP 账号、P2P 和 Relay 环境保持原配置，四类召唤地址与私服轮询参数从实际私服 ss.info 取得。公共密码不会传给游戏进程或私服，私服密码也不会用于公共认证。

## 验证范围

已完成真实已有账号的 NP 认证、实际适配器的公共游戏登录与只读笔记查询，游戏登录和查询均为 HTTP 200 / ResKind 0；指定查询返回空笔记列表。离线回环测试覆盖身份隔离、召唤路由、房主位置响应头、断线报错、协议拒绝与关闭清理。本轮没有发布公共笔记或启动真实游戏。

待定向验收的问题是：真实角色在游戏里能否显示公共内容，以及使用公共游戏会话时，两台电脑能否继续通过原私服正常入房、离开并保存。此前双机结果使用私服自己的游戏登录，不能回答这条新调用路径。未改动的 Boss、个人商店、徽章、掉落等验收继续复用。
