# 退出到桌面的中文文本兼容

BBport 1.9.4新增了标题与游戏系统菜单的“退出到桌面”。部分游戏汉化MOD用完整的menu.msgbnd.dcx覆盖菜单文本，可能将新增条目盖回“意见箱”、缺失名称或缺失说明。

The Hunt在最终MOD之后生成一个小型文本兼容层，仅补入退出所需的五条文本。其他译文、字体和游戏资源不变；使用英文语言目录承载中文重译的MOD也保留中文。兼容层由当前实际生效的菜单文本生成，汉化更新后自动使用新输入，原游戏和原MOD文件不写入。

该处理只在BBport已生成退出功能层时启用，不擅自更改quit_to_desktop设置。若普通版关闭此功能，无缝版继续沿用关闭状态。

系统菜单的直接退出仍通过原版保存退出流程。文本兼容已通过自动检查和真实汉化档对照，入口的取消、确认、合作收尾和重载已有下述独立实机记录；两个退出入口分别按各自证据验收。

2026-10-27 已补完系统菜单入口的独立副本实测：单机、房主、客机的取消和确认均正常；房主退出后客机返回自己的世界，客机退出后房主正常移动；客机重载后原生保存的主文件与备份核对完成。此结论适用于本项目测试版本，不代表已定位上游原版 BBSC issue #41。标题菜单退出另有用户明确确认，按未改动路径复用；不同入口及版本边界见[当前验收表](validation-current.md)。

兼容输出按内容摘要缓存于引擎输出目录的quit-text-compat下，输入不变时复用，新的汉化不会沿用旧文本。无需手动修改汉化包。洗点功能不受这项补丁影响，目前仍保持原先的无缝版限制。
