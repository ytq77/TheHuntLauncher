# The Hunt 客户端升级

preview.7 新增自动更新。已经安装带更新模块的版本时，可点击「启动游戏」旁的「检查更新」，查询后点击「自动更新」。程序会下载并校验完整包，备份被替换的程序文件，再重新打开；账号、存档和本机设置保持原位。网络选项和恢复说明见[自动更新](updates.md)。

此前公开版本没有更新模块，首次升级到 preview.7 仍需按以下步骤手动覆盖。单纯重新打开不会下载更新。

## 同一台电脑覆盖升级

1. 正常退出游戏和 The Hunt 启动器。
2. 备份这台电脑的 `data/user/savedata`、`profile.json`、`.private`、`features.json` 和 `server-admin.json`（文件不存在则跳过）。转换任务和旧存档备份可一并保留。
3. 下载完整 Windows 客户端 ZIP，先解压到临时目录。
4. 把包内的程序文件和子目录复制到原 The Hunt 目录，允许替换同名程序文件。不要把外层带版本号的文件夹套进旧目录形成嵌套安装。
5. 原目录的 `data`、账号和个人配置保留。重新打开 `BBSC-Launcher.exe`，核对左下角版本、画质来源和联机账号。

公开客户端包不包含私人存档、账号、个人功能设置或已配置服务器，因此程序覆盖升级不应替换这些文件。若后续版本需要数据迁移，将在对应发布说明中单独注明。

每台电脑保留自己的配置。不要通过复制另一台电脑整份 The Hunt 目录来升级，否则会混入对方的存档、路径和配置；账号凭据还与原 Windows 用户绑定。

## 普通版启动器更新

普通版更新不会自动升级 The Hunt 内固定的 BBport／BBSC 核心。The Hunt 每次启动会读取本机普通版画质设置，更新普通版后仍需核对设置是否兼容。新的核心适配需经验证后随 The Hunt 新包发布。

## 1.9.4 适配版

本包同步普通版画质、低显存开关及按键，包含新图形组件，修正模组加载器使能力检测工具目录改变的问题。已有无缝版的按键首次被同步替换前会备份到 `data/input.before-settings-sync.ini`。如果你单独修改了无缝版按键，请先保留自己的文件；之后应在普通版修改需要同步的按键。

无缝环境暂时覆盖 `rebirth=0`，并不修改普通版配置。新版核心仍需单机和双机实测后才能作为已验证升级发布。
