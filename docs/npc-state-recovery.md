# 梦境往返后的客机 NPC 状态恢复

## 修复内容

房主和客机的 NPC 剧情进度不同时，客机进入房主世界会临时看到房主的状态。此前 BBSC 入房前只保留地图组，进入房主梦境时才记录部分全局组，此时实时值已经属于房主；回家后，这份错误副本可能再次覆盖游戏刚恢复好的客机状态。

preview.9 在接受召唤、尚处于自己世界时，同时留存梦境所需的全局组。应用房主梦境状态时，恢复副本取自入房前日志；没有可信原值的全局组不会从客机实时表重新建立“自己的原值”。地图组保留既有的备份路径。

## 已验证范围

BBport 1.9.4、游戏 CUSA03173 1.09，双人隔离存档测试：

1. 客机自己的小教堂四位 NPC 均在场。
2. 客机进入房主世界，跟随提灯回猎人梦境，再跟随回小教堂。
3. 房主使用空枪菜单选择遣返客机。
4. 客机回到自己的世界，四位 NPC 均在场。
5. 正常保存退出，再单人重载，四人仍在场。

恢复入口/出口的原生跟踪与主存档、游戏备份的完整副本均核对通过；另一角色的数据未变。对照旧代码，同一路径可复现 NPC 状态被错误日志覆盖。诊断代码与私人测试存档不进入正常安装包。

构建中的原生回归测试提取实际准备后的 BBSC 函数，使用模拟内存表、时序及日志 I/O 和合成任务状态，覆盖预先留存、正常恢复、重复应用/多轮会话、缺少可信原值、崩溃日志恢复及商店购买记录。函数测试不替代游戏实测。

死亡、强退、入侵及交换房主的组合尚未做这轮实机复测。之前另行发现的“组暂不可读时重试”候选没有合入本次修改。

## 对已有存档的影响

此补丁防止后续同类错误，不自动补 NPC、回滚剧情或修改历史存档。已经受影响的存档，需要结合该角色较新的完整副本及可确认的历史状态单独核对；不要用另一玩家的整组剧情数据覆盖，也不要直接把旧备份覆盖到新进度。
