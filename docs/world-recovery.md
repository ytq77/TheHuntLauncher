# 合作退出与自己的世界恢复

从游戏系统菜单确认退出后，模组释放保持联机的补丁，让游戏按原有流程离房并回到标题。取消退出确认不会结束合作。客机退出后，请正常关闭游戏窗口再重新读档，避免在同一进程里重新套用旧会话状态。

## 正常流程

1. 入房前保存自己的世界基线和固定存档位置。
2. 确认退出时冻结本次恢复记录；游戏进程完全结束后，启动器先备份再核对当前角色主文件。
3. 启动器只处理主文件的对应事件区；不会把旧一代备份的背包与新世界状态拼接起来。
4. 下次独自加载对应角色并正常保存。正确恢复结果的加载凭据，以及后续原生保存的事件区摘要，需要与两代实际存档匹配，才算完成。
5. 完成后归档世界记录并解除本轮等待。历史归档不会再写回角色。

地图加载时，部分事件执行标记会变化。因此，不能要求恢复后的每个差异位永远保持旧值，也不能简单忽略整组状态。新确认路径保留输入、角色身份、会话令牌和保存依据；只有游戏确实加载了正确结果，并写入两代角色文件后，才接受这些后续变化。

## 看到等待提示时

“正在核对世界恢复与游戏备份”是状态通知，通知消失本身不代表任务已完成。请独自加载同一角色、正常保存退出；若反复提示或启动器报告未完成，请保留日志、存档和辅助记录后反馈。

- 不要删除或手动重命名`mod/own-world`里的待确认记录。
- 不要删除`data/user/world-recovery`里的任务、输入和备份。
- 不要用其他角色、其他电脑的辅助记录替换当前记录。
- 核对未完成时会暂缓鸣铃、共享进度合并和存档转换；缺少依据时不会自动覆盖后来的进度。

普通版与无缝版真实存档仍独立。本流程的备份、任务和凭据均为本机个人数据，不包含在公开发布包中。
