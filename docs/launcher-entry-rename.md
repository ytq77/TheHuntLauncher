# preview.18 启动入口更名

客户端编译输出和完整包入口改为 `TheHuntLauncher.exe`，可选启动脚本改为 `START-TheHunt.cmd` 并指向新 exe；BBSC 模组名称、上游署名和目录互斥锁协议保留。独立服务端仍为 `Server.exe`。

preview.18 使用新入口；preview.17 的历史附件、既有录制目录与对应镜头仍使用 `BBSC-Launcher.exe`。若换新版录制，需要同步 P2-04、文件名特写与公共账号设置镜头。

更名前的 preview.17 更新助手固定要求旧 exe 名称，无法自动安装仅有新入口的包；它会在替换程序前拒绝缺少旧入口的包。按此前不维护早期测试版兼容包的决定，本次不新增旧名副本或兼容启动程序。首次切换这次更名版本使用新目录完整包，保留原测试目录及进度，存档按既有已验证流程处理。新名称版本之间继续使用正常自动更新。

更名检查覆盖：无界面编译、新名称入口与启动脚本引用、临时安装的新名程序更新和重启、账号/存档字节保留及旧安装拒绝。完整包及 WPF 检查由发行构建执行；新名称游戏启动与公共/私服混合路径的实机验收仍单独记录，之前通过的 Boss、奖励等未改范围继续复用。
