# 桌面界面改版（2026-11-21）

本轮只改界面：主题、排版、页面图片、图标和一处只读数据读取。游戏启动、联机、存档写入和后端脚本均未改动。

## 界面

- 字体：标题用 Noto Serif CJK，正文、表单和开服窗口用 Noto Sans CJK。不再使用霞鹜文楷，字体文件及许可已从 `assets/fonts/` 移除。
- 颜色：金色只用于可操作或已选中的元素（主按钮、开关、当前导航、选中行、链接），标题用米白色；会覆盖进度的操作保留暗红。
- 各页顶部改为无边框页头图，向窗口顶边和右边延伸并渐隐；正文字号、导航和列表行距整体收紧，列表从逐条描边改为细线分隔。
- 首页：出发前检查、本次玩法、角色、奖杯四张卡，左右两列底部对齐。
  - 「角色」来自最近一次已校验的启动前／恢复前备份（`save_backups.py` 的 `list`），启动时读取一次，存档页刷新后同步。它显示的是备份时的角色，不是当前存档的实时状态；卡片上注明来源备份时间。
  - `list` 在存在 `.save-import.lock`（导入或恢复中断）时会先收尾那次恢复，属于写操作。因此首页遇到该锁文件时不读取，提示到存档页处理，保证启动时只读。
  - 「奖杯」显示进度和最近解锁的三项，沿用启动时已有的奖杯读取，不增加请求。
- 存档页：备份列表改为逐行显示（类型、时间与角色），选中行右侧显示角色表；「打开备份目录」「刷新」移到区块标题右侧。
- 侧栏新增「创建桌面快捷方式」：在桌面生成「The Hunt Launcher」快捷方式，指向当前启动器。已存在且指向其他位置时先确认。程序文件名仍为 `TheHuntLauncher.exe`，以免影响自动更新（见 [启动入口更名](launcher-entry-rename.md)）。
- 图标：改用 iytq 提供的金色手铃图（`assets/artwork/icon-bell.png`），启动器与开服窗口共用；缺少该文件时 `make-icon.ps1` 回退到原矢量铃铛。
- 页面图片和图标的原始文件摘要见 `assets/artwork/provenance.json`。
