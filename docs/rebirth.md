# 人偶洗点：当前支持范围

**The Hunt 无缝版暂不支持人偶洗点。** 当前固定 `rebirth=0`、`BB_REBIRTH=0`，不修改普通版的洗点设置。普通版即使开启，无缝版也不会自动开启。

原因是洗点补丁与本项目的灵视退款保护使用同一个函数入口，尚未完成共同适配；此外，尚未分配的免费等级额度单独保存在用户目录的 `rebirth.txt`，不能只靠复制角色存档保证迁移。本项目也尚未完成合作中洗点的运行验证。

## 需要洗点时

可以使用 BBport 普通版的人偶洗点功能：

1. 正常退出两边游戏，确认要保留哪份角色进度。如果较新进度在无缝版，先按[存档转换说明](save-conversion.md)转换并备份后替换普通版。
2. 在普通版启动器启用人偶洗点，进入自己的世界找人偶操作。当前 BBport 1.9.4 消耗 5 点灵视，回到出身属性后，在升级界面免费重新分配到洗点前的等级。
3. **先分配完全部免费等级，确认已回到洗点前等级，再正常保存退出。不要把洗点到一半的角色直接导入无缝版。** The Hunt 当前不迁移 `rebirth.txt` 中尚未使用的额度。
4. 在 The Hunt「存档」页选择从普通版导入。导入会备份并整体替换无缝版全部角色进度，不是只同步属性，也不合并两边独立游玩的进度。请先核对来源。

上述方法使用普通版自身的洗点，再沿用已有存档导入；不代表已验证无缝联机过程中直接洗点。仅替换普通版存档、没有再导入时，无缝版仍使用自己的独立存档。
